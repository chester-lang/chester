Mathematically Verified

Chester's core compiler pipeline is fully extracted from Coq/Rocq proofs. Its parser, elaborator, and type checker have strong structural guarantees, ensuring the compiler doesn't miscompile valid code.

True Theorem Proving

Inspired by Lean and Idris 2, Chester supports a rigorous universe hierarchy (Type 0, Type 1...), dependent types, and compile-time beta evaluation via Weak Head Normal Form (WHNF).

Extensible Syntax

Shape the language to your domain. Chester supports hygienic macros that prevent variable capture, topological Pratt parsing for custom operator precedence, and Scala-style extension methods.
