# Chester Documentation

Documentation for the verified Chester language (Coq/Rocq theories → extracted OCaml
compiler → TypeScript / Go / Rocq backends).

The book is split into three audiences, matching the layout used in the 2026 draft docs:

1. **[Guide](guide/README.md)** — tutorials and conceptual explanations for new users
2. **[Reference](references/README.md)** — technical specs (grammar, surface forms) for language users and implementers
3. **[Paper](paper/README.md)** — literature, formal foundations, and academic reading

Start with [Getting Started](guide/getting-started.md) if you want to build and run a
program today.
